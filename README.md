# 📊 Olist E-Commerce Sales Dashboard

Business Analysis Project using SQL • PostgreSQL • Power BI

# 📌 Executive Summary

This project analyzes the Brazilian Olist E-Commerce dataset to uncover business insights related to revenue, customer behavior, product performance, payment trends, seller performance, and monthly order growth.

The project demonstrates an end-to-end Business Analyst workflow:
- Data Analysis using SQL
- Business KPI Identification
- Dashboard Development in Power BI
- Business Insights & Recommendations
  
# 🎯 Business Objectives
- Analyze Total Revenue
- Analyze Monthly Orders
- Understand Customer Behaviour
- Identify Top Selling Categories
- Analyze Seller Performance
- Compare Payment Methods
- Track Order Status
- Support Business Decisions

### Products
- Health & Beauty generated the highest sales.

- Top sellers contributed a major portion of revenue.
